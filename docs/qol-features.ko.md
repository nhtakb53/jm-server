# 정만서버 편의 기능

정만서버 전용 `JMServer` 모드 프로필에서만 적용되는 데이터 기반 편의 기능입니다. 두 사람 모두 같은 런처 버전으로 D2RLoader를 다시 설치한 뒤 사용해야 합니다.

## 아이템 정보와 수량

- 무기, 방어구, 반지, 목걸이, 참, 주얼의 상세 정보에 아이템 레벨이 표시됩니다.
- 마을 차원문의 고서와 감별의 고서는 최대 100개까지 보관합니다.
- 열쇠는 최대 50개, 화살과 쇠뇌용 화살은 최대 500개까지 보관합니다.
- 서버가 처음 만들고 이후 보충하는 Advanced Stash에는 게임 데이터상 중첩 가능한 전체 91종이 D2R에서 실제 인출 가능한 최대값인 99개씩 들어갑니다. 룬·보석뿐 아니라 회복 물약, 열쇠·장기, 면죄 재료, 월드스톤 조각과 고대 소환 재료도 포함하며 별도의 가짜 스택 아이템은 사용하지 않습니다.

## 전체 자동지도

유효한 레벨 프리셋 1,092개의 `AutoMap`을 활성화합니다. 마을과 던전·야외 구역에 진입하면 탐색하기 전에도 해당 구역의 전체 지도가 공개되며, `Tab`으로 원래 자동지도 화면을 켜고 끕니다. 실행 파일 메모리 패치나 외부 지도 오버레이는 사용하지 않습니다.

정만서버는 난이도별 자동지도 보조 파일 `.ma0`, `.ma1`, `.ma2`, `.ma3`와 `.map`도 캐릭터 프로필에 포함해 서버에 저장합니다.

## 베이스와 재료 보급

상인에게서 첫 번째 선택권을 구입한 뒤 호라드림의 함에서 항목을 고릅니다.

| 상인 | 선택권 |
| --- | --- |
| 아카라 | 베이스 무기 8분류, 베이스 방어구 7분류, 룬, 보석, 참과 주얼, 스킬참 8직업, 인기 스몰참·라지참의 첫 선택권 |

| 조합 | 결과 |
| --- | --- |
| 선택권 + 마을 차원문의 두루마리 | 다음 선택권 + 사용한 두루마리 |
| 선택권 + 감별의 두루마리 | 이전 선택권 + 사용한 두루마리 |
| 재료 선택권 + 열쇠 | 선택한 재료 + 선택권 + 열쇠 |
| 베이스 선택권 + 일반/고급 작업석 | 일반 또는 고급 레벨 99 베이스 + 선택권 + 작업석 |
| 베이스 선택권 + 매직 크래프트 작업석 | 레벨 99 매직 크래프트 재료 + 선택권 + 작업석 |
| 베이스 선택권 + 에테리얼/고급 에테리얼 작업석 | 원본 규칙상 허용되는 에테리얼 베이스 + 선택권 + 작업석 |
| 참 선택권 + 옵션 작업석 | 고정 접두사와 선택 접미사가 붙은 레벨 99 매직 참 + 선택권 + 작업석 |

508종의 베이스는 무기 8분류와 방어구 7분류 안에서 각각 독립적으로 순환합니다. 퀘스트 아이템과 투척 물약은 베이스 목록에 들어가지 않습니다. 생성되는 베이스의 아이템 레벨은 99이며 직업 전용 스태프 모드·오토매직·고급 옵션의 개수와 조합은 D2R 원본 규칙을 유지합니다. 내구도가 없거나 활·석궁처럼 원래 에테리얼이 될 수 없는 베이스에는 에테리얼 조합이 생성되지 않습니다.

고급·고급 에테리얼 베이스의 고급 옵션 수치는 방어력/피해 증가 14~15%, 최대 내구도 15%, 명중률 +3으로 제한됩니다. 방어구는 원본의 방어력 증가, 내구도, 두 옵션 조합만 사용하며 80% 확률로 두 옵션이 함께 붙습니다. 무기는 원본의 명중률, 피해 증가, 내구도 및 허용된 두 옵션 조합만 사용하며 85% 확률로 두 옵션, 80% 확률로 피해 증가가 포함됩니다. 무기에 세 옵션이 동시에 붙는 등 원본 한도를 넘는 조합은 만들지 않습니다.

스킬참은 아마존부터 악마술사까지 8직업×3계열 24종입니다. 스몰참과 라지참은 피해·명중률, 모든/단일 저항, 마나, 원소·독 피해의 인기 접두사 각 11종을 제공합니다. 참 옵션 작업석은 선호 옵션 랜덤, 생명력, 빠른 타격 회복, 달리기·걷기 속도, 힘, 민첩, 마법 아이템 발견(스몰참 전용) 7종이며 고정 접미사는 최고 등급의 상위 10% 수치를 사용합니다.

빠른 크래프트는 레벨 99 매직 베이스와 `빠른 크래프트 작업석`만 넣어 원본 Blood·Caster·Hit Power·Safety 36종 중 베이스에 맞는 결과를 만듭니다. 원본 고정 옵션과 결과 레벨 계산은 그대로이고, 레벨 99 재료에서는 원본 규칙상 무작위 접사 최대 4개가 붙습니다. 작업석은 반환됩니다.

## 호라드림 작업대

| 조합 | 결과 |
| --- | --- |
| 소켓 아이템 + 감별의 두루마리 | 장비 본체와 옵션을 유지하고 소켓 내용물 제거 |
| 소켓 없는 무기 + 1~6소켓 작업석 | 작업석에 표시된 수만큼 소켓 추가 |
| 소켓 없는 방어구 + 1~4소켓 작업석 | 작업석에 표시된 수만큼 소켓 추가 |
| 비에테리얼 무기/방어구 + 열쇠 | 내구도 수리 및 충전 회복 |
| 상위 룬 + 감별의 두루마리 | 직전 룬 2~3개 |
| 상위 보석 + 감별의 두루마리 | 직전 등급 보석 3개 |

아카라의 일반 상점에서 `1소켓 작업석`부터 `6소켓 작업석`까지 각각 1골드에 구입합니다. 작업석은 겹쳐지지 않으며 소켓 조합에 소모됩니다. 일반·고급·저품질 베이스는 무기 1~6개, 방어구 1~4개 중에서 고를 수 있고 베이스의 `gemsockets`와 아이템 레벨 상한을 넘지 않습니다. 매직 장비는 최대 2개, 레어·제작·세트·유니크 장비는 원본 품질 규칙대로 최대 1개만 가능합니다. 이미 소켓이 있는 장비에는 추가할 수 없습니다.

룬과 보석의 상위 조합은 게임의 기존 조합식을 그대로 사용할 수 있습니다. 재사용 촉매로 사용된 감별 두루마리와 수리용 열쇠는 결과에 함께 돌아옵니다. 단, 소켓 제거의 `useitem,rem`은 박혀 있던 룬·보석·주얼을 돌려주지 않으므로 귀중한 재료가 든 장비에는 주의해서 사용해야 합니다.

## 공식 전리품 필터

런처 설정에서 **전리품 필터 복사**를 누른 다음 D2R의 전리품 필터 화면에서 가져오기 버튼을 누르고 `Ctrl+V`로 붙여 넣습니다.

기본 프로필은 유니크·세트, 룬, 상급 보석, 참·주얼, 에테리얼/소켓 엘리트 베이스와 제작 재료를 우선 표시합니다. 기본 상태에서는 어떤 아이템도 숨기지 않습니다. 낮은 등급 물약 숨김 규칙은 꺼진 선택 항목으로만 포함됩니다.

## 주의

- 이 기능은 Battle.net 캐릭터가 아닌 정만서버 전용 저장 경로에만 사용합니다.
- 캐릭터와 공유 창고를 다른 모드 또는 원본 게임으로 직접 열지 마세요.
- D2R 업데이트 후에는 런처의 버전 검증이 통과하기 전까지 실행하지 마세요.

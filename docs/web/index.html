중앙 저장

캐릭터와 같은 계정의 소프트코어 공유 보관함 전체를 PostgreSQL 서버 프로필로 체크아웃·체크인합니다. 계정이 다른 ht와 jm의 캐릭터·보관함은 서로 섞이지 않습니다.

인게임 보급

런처 아이템 편집기는 없습니다. 도박, 상인이 파는 선택 카드, 호라드림의 함을 이용해 게임 안에서 장비를 준비합니다.

TCP/IP PK

인증·캐릭터 서버는 TCP 15570, 인터넷 게임 중계는 TCP 15571을 씁니다. D2R 내부 포트 4000은 런처가 자동 중계합니다.

이 서버만 설치하면 게임이 생기는 구조가 아닙니다. 플레이 PC마다 정식 Diablo II: Resurrected 설치와 본인이 이용할 수 있는 게임 라이선스가 필요합니다. 워락을 만들려면 해당 DLC 이용 권한도 필요합니다.

처음 설치부터 플레이까지

1. 준비물

  • Windows 플레이 PC, 정식 D2R 3.2.92777 설치, 정만서버 런처 정만서버.exe
  • 검증된 원본 D2RLoader-1.0.1-beta.zip. ZIP은 정만서버 배포본에 포함되지 않으므로 PC마다 따로 준비합니다.
  • 관리자에게 받은 장치 ID와 장치 토큰. 토큰은 비밀번호이므로 채팅·가이드·스크린샷에 공개하지 않습니다.

2. 런처 설정

  1. 정만서버.exe를 실행하고 설정 탭을 엽니다.
  2. 외부 접속은 서버 주소 118.216.89.185, 포트 15570, TLS 사용을 입력합니다. 같은 LAN에서만 시험할 때는 192.168.0.10:15570을 쓸 수 있습니다.
  3. 서버 인증서 SHA-256에 60ABE0942C2D7CCB45461B623B49DC9FDC5607FB275AE6118D7F593274FEDA3A을 입력합니다.
  4. 자신의 장치 ID와 토큰을 입력하고 연결 시험을 누릅니다. 계정 이름과 캐릭터 목록이 나오면 인증 성공입니다.
  5. D2R 설치 폴더와 원본 D2RLoader-1.0.1-beta.zip을 지정합니다.
  6. 화면 모드에서 전체 화면 또는 창 모드를 선택합니다. 창 모드라면 원하는 해상도도 선택합니다.
  7. Battle.net, Agent, D2R, D2RLoader를 모두 종료한 뒤 D2RLoader 설치/복구를 누릅니다. 로더 제한 설정과 정만서버 모드 18개 파일이 함께 설치됩니다.
  8. 설치 검증에서 D2R·로더·모드가 모두 유효한지 확인한 뒤 설정 저장을 누릅니다.

화면 설정: 창 모드는 1280×720, 1366×768, 1600×900, 1920×1080, 1920×1200, 2560×1080, 2560×1440, 2560×1600, 3440×1440, 3840×2160 중에서 선택합니다. 전체 화면은 D2R의 동작에 따라 Windows 바탕화면 해상도를 사용합니다. 선택값은 정만서버 전용 Settings.json에만 기록되며 기존의 다른 그래픽 옵션은 보존됩니다.

설치 중 “D2RLoader 원본 ZIP을 찾을 수 없습니다”가 나오면 설정 탭에서 ZIP을 다시 직접 선택하세요. 폴더를 지정하는 것이 아니라 확장자가 .zip인 원본 파일을 지정해야 합니다.

3. 캐릭터 만들기

  1. 플레이 탭에서 새로고침을 눌러 서버에 연결합니다.
  2. 신규 캐릭터를 누르고 이름과 직업을 고릅니다. 생성 프리셋은 하나뿐이며 언제나 99레벨 완성 캐릭터입니다.
  3. 목록에 새 캐릭터가 보이면 선택합니다. 첫 캐릭터를 만들 때 그 계정 전용 공유 보관함도 함께 만들어집니다.

4. 혼자 파밍·세팅하기

  1. 모든 Battle.net·D2R 관련 프로세스를 종료합니다.
  2. 플레이 탭에서 캐릭터를 선택하고 선택 캐릭터 혼자 플레이를 누릅니다.
  3. 런처가 계정의 모든 캐릭터와 공유 보관함을 서버에서 내려받고 D2RLoader를 엽니다.
  4. D2R에서는 TCP/IP 화면만 사용합니다. 런처에서 선택한 것과 같은 서버 캐릭터를 골라 게임을 만듭니다. Online 탭은 열지 않습니다.
  5. 게임 안에서 도박·선택 카드·큐브식으로 세팅합니다.
  6. 끝나면 메뉴의 저장 후 종료로 게임을 닫고, 런처 로그에 프로필 리비전 … 저장 완료가 나올 때까지 런처를 닫지 않습니다.

화면 밝기 같은 초기 설정은 기본 D2R의 Settings.json을 정만서버 전용 저장 폴더로 가져오고 이후 사용자가 바꾼 값을 유지합니다. 계속 초기 설정이 뜨면 D2R과 로더를 종료하고 설치/복구를 한 번 실행하세요.

두 사람이 PK하는 방법

HOST

방장

  1. 플레이 탭에서 사용할 캐릭터를 고릅니다.
  2. PK 방 만들기를 누르고, 친구가 접속할 수 있는 방장 PC의 공인 IPv4를 입력합니다.
  3. 런처가 방장 PC의 TCP 15571을 D2R의 로컬 TCP 4000으로 중계합니다.
  4. D2RLoader가 열리면 TCP/IP → 게임 방 만들기를 선택합니다.
GUEST

참가자

  1. 플레이 탭에서 방 목록 새로고침을 누릅니다.
  2. 캐릭터와 친구의 방을 선택하고 선택 방 참가를 누릅니다.
  3. 런처가 로컬 127.0.0.1:4000을 방장 공인 주소의 15571로 중계합니다.
  4. D2R에서 TCP/IP → 게임 참가를 누르고 주소에 127.0.0.1을 붙여 넣습니다.

서버 저장, 체크아웃과 복구

시작할 때

선택한 캐릭터 하나만이 아니라 계정의 등록 캐릭터 전부와 공유 보관함을 하나의 프로필로 내려받습니다. 서버 임대 시간은 2분, 게임 중 갱신 간격은 40초입니다.

게임 중

전용 저장 경로는 %USERPROFILE%\Saved Games\Diablo II Resurrected\Mods\JMServer입니다. 같은 계정 프로필은 동시에 두 장치에서 열 수 없습니다.

종료할 때

D2RLoader와 D2R 프로세스가 모두 끝난 뒤 5초를 기다려 파일을 수집하고 서버에 새 리비전으로 저장합니다. 성공하면 로컬 체크아웃 파일을 지웁니다.

정상 종료 순서

  1. D2R 메뉴에서 저장 후 종료합니다.
  2. D2R과 D2RLoader 창이 모두 닫혔는지 확인합니다.
  3. 런처 로그에서 게임 프로필을 정만서버에 저장하는 중 다음 프로필 리비전 … 저장 완료를 확인합니다.
  4. 저장 완료 후에 런처를 닫습니다.

충돌·인터넷 끊김 뒤 복구

  1. 복구 필요가 보이면 새 게임을 시작하지 않습니다.
  2. Battle.net, Agent, D2R, D2RLoader를 모두 종료합니다.
  3. 런처의 복구 체크인을 누릅니다.
  4. 프로필 리비전 … 복구 완료를 확인한 뒤 새로고침하고 플레이합니다.

전용 저장 폴더를 직접 삭제하거나 다른 세이브를 덮어쓰지 마세요. 기존 로컬 전용 세이브와 게임 중 새로 생긴 미등록 캐릭터는 삭제하지 않고 %LOCALAPPDATA%\JM Server\quarantine으로 격리됩니다.

안전 범위와 문제 해결

  • 정만서버는 Battle.net 계정·온라인 캐릭터·프로토콜을 읽거나 수정하지 않습니다. 저장 경로도 Mods\JMServer로 분리합니다.
  • D2RLoader 실행 중에는 Online 탭에 접속하지 않고 TCP/IP만 사용합니다.
  • 메모리 패치, 개발자 콘솔, 전역 확장, 모드 확장을 사용하지 않습니다.
  • D2R·D2RLoader·모드 해시가 고정값과 다르면 런처가 실행을 거부합니다.
  • 제3자 로더 사용의 위험을 0으로 보장할 수는 없습니다. 정만서버 전용 세이브를 Battle.net이나 일반 오프라인 저장과 섞지 마세요.

# 인게임 아이템 보급소

정만서버 아이템 보급소는 런처에서 아이템을 생성하지 않는다. D2R 안에서 상인과 호라드림 함만 사용하며, 서버 전용 `JMServer` 모드 프로필에만 적용된다.

현재 D2R `3.2.92777` 데이터에 고정된 유니크 410종과 세트 140종을 제공한다. 원본에서 같은 이름을 공유하는 무지개 자락 8종은 원소와 발동 조건별로 각각 선택할 수 있도록 분리했으며, 퀘스트 전용으로 정의된 유니크 6종은 제외한다. 플러그인, 개발자 콘솔, 메모리 패치는 사용하지 않는다.

## 1. 미확인 아이템 얻기

기드 등 도박 상인의 **도박** 화면을 연다. 원하는 기본 장비가 없으면 화면을 닫았다 다시 열어 목록을 갱신하고, 원하는 기본 장비를 구매한다. 품질 확률은 유니크 1%, 세트 1%, 레어 80%, 매직 18%다.

- 나머지 18%는 매직으로 나오며 레어를 주 결과로 삼는다.
- 유니크·세트·룬워드·큐브 제작식의 숫자 가변 수치와 베이스 방어력은 원래 최소~최대 범위의 상위 25%에서만 결정된다. 예를 들어 마라의 만화경 모든 저항 20~30은 28~30, 소집의 전투 명령 1~6은 5~6, 슬픔 추가 피해 340~400은 385~400이 된다. 음수 페널티는 0에 가까울수록 좋은 값으로 계산하여 원소 파괴참 저항 -90~-70은 -75~-70, 뼈의 분쇄 물리 피해 페널티 -20~-10은 -12~-10이 된다. 갑옷·투구·방패 등 베이스 방어력도 같은 기준을 적용하여 더스크 슈라우드 361~467은 441~467이 된다.
- 매직·레어 접사와 직업 전용 자동 옵션의 숫자 가변 수치는 더 강하게 원래 범위의 상위 10%에서만 결정된다. 매직과 레어는 같은 접사 표를 사용하므로 이 수치 개선은 두 품질에 함께 적용된다. 고정 수치, 발동 확률·기술 레벨, 횃불의 무작위 직업 ID처럼 하나의 능력 수치가 아닌 구조화 필드, 시각 효과, 사용되지 않는 필드, 값이 커질수록 불리한 요구 레벨·요구 능력치 필드는 유지한다.
- 고급·고급 에테리얼 베이스는 원본 `QualityItems` 조합만 사용하면서 방어력/피해 증가 14~15%, 최대 내구도 15%, 명중률 +3으로 굴린다. 방어구는 80% 확률로 두 옵션, 무기는 85% 확률로 두 옵션이 붙고 무기의 80%에는 피해 증가가 포함된다. 원본상 불가능한 무기 3옵션 조합은 생성하지 않는다.
- 매직·레어 접사의 원래 `frequency`에 접사 레벨별 가중치를 곱한다. 레벨 0~19는 ×1, 20~39는 ×3, 40~59는 ×6, 60~79는 ×10, 80 이상은 ×15다. 접사를 제거하지 않고 고레벨 접두사·접미사의 상대 확률만 높이므로 낮은 옵션도 드물게 나올 수 있다.
- 이 규칙은 도박 출처만 구분할 수 없는 데이터 모드 특성상 같은 베이스에서 새로 드롭되거나 선택 카드로 생성되는 아이템에도 적용된다. 이미 생성된 아이템의 옵션은 바뀌지 않는다.
- 대상 기본 장비와 업그레이드 장비군의 데이터 비용은 1골드로 낮췄다. 0골드는 반지·목걸이·주얼 거래 검증에 실패하므로 사용하지 않는다. 무기·방어구는 D2R 엔진이 캐릭터 레벨 기반 가격을 추가로 계산할 수 있다.
- 아카라의 일반 상점에서 초록색 `유니크 선택: 기드의 행운` 선택 카드를 산다. 다른 이름이면 카드+마을 차원문의 두루마리로 다음, 카드+감별의 두루마리로 이전 항목을 선택한다. 카드+열쇠를 변환하면 상점 가격 99% 감소가 붙은 기드의 행운을 얻는다. 인벤토리에 두면 도박 가격도 현재 표시 가격의 약 1/100로 내려간다. 모드 적용 후 일반 몬스터가 드롭한 새 기드의 행운에도 동일한 할인이 붙지만, 모드 적용 전에 생성된 기존 참은 새로 획득하는 편이 확실하다.
- 레벨 99 완성 캐릭터가 전체 카탈로그를 굴릴 수 있도록 대상 레벨을 최대 85로 맞췄다.
- 일반 유니크는 같은 아이템도 반복해서 얻을 수 있다. 단, `Gheed's Fortune`, `Annihilus`, `Hellfire Torch`는 원본의 서로 다른 단일 소지 그룹을 유지한다. 같은 종류는 1개만 들 수 있지만 세 종류는 각각 1개씩 동시에 소지할 수 있으며 선택 카드로 생성한 아이템에도 같은 제한이 적용된다. 횃불의 직업 기술은 8직업 전체에서 결정된다.
- 무지개 자락은 `번개·냉기·화염·독` × `사망 시·레벨 상승 시`의 8개 카드로 따로 표시된다. 원하는 원소와 발동 조건이 적힌 카드를 고른 뒤 열쇠와 조합한다. 피해 증가와 적 저항 감소는 상급 옵션 편향 규칙에 따라 모두 최상값인 `+5% / -5%`로 생성된다.
- 도박으로 받은 아이템은 D2R의 원래 동작대로 미확인 상태다.
- 퀘스트 플래그가 있는 기본 아이템은 도박 목록과 선택 카드에서 모두 제외한다.
- 모든 선택 카드는 상점 슬롯에서 잘리거나 빈칸으로 보이지 않도록 1×1 전용 HD 아이콘을 사용한다. 유니크는 금색, 세트는 초록색, 베이스는 은색 계열로 품질을 구분하고 무기 8분류·방어구 7분류·장신구·재료·8개 직업 스킬참·옵션 및 소켓 작업석마다 고유 문양을 사용한다. 열쇠로 생성한 실제 장비와 재료는 원래 HD 아이콘과 인벤토리 크기를 그대로 사용한다.

작은·큰·거대 부적은 게임의 도박 대상 규칙과 맞지 않아 도박 목록에 넣지 않았다. 유니크 보석은 포함된다. 재료 선택 카드에서는 기본 큐빙과 중복되는 일반 거대 부적을 제외하고 작은 부적·큰 부적·주얼만 제공한다. 기드의 행운·파괴참 같은 유니크 거대 부적은 유니크 선택 카드에서 그대로 고를 수 있다.

## 2. 원하는 이름을 정확히 선택하기

액트 1의 아카라가 55개 분류의 첫 번째 선택 카드를 모두 일반 상점에서 판다. 카드 이름은 현재 선택된 실제 아이템의 공식 게임 번역을 사용하므로 한국어 클라이언트에서는 `유니크 선택: 기드의 행운`, `베이스 방패 선택: 이지스`처럼 표시된다. 유니크 카드는 완벽한 토파즈, 세트 카드는 완벽한 에메랄드 모양이다. 베이스 작업석 5종, 참 옵션 작업석 7종, 빠른 크래프트 작업석 1종, 소켓 작업석 6종도 함께 판매하므로 아카라의 정만서버 전용 진열 항목은 총 74개다.

카드와 재료를 호라드림 함에 넣고 변환한다.

| 조합 | 결과 |
| --- | --- |
| 선택 카드 + 마을 차원문의 두루마리 | 다음 아이템 카드 + 사용한 두루마리 |
| 선택 카드 + 감별의 두루마리 | 이전 아이템 카드 + 사용한 두루마리 |
| 유니크·세트·재료 카드 + 열쇠 | 선택한 정확한 아이템 + 같은 카드 + 열쇠 |
| 베이스 카드 + 베이스 작업석 | 선택한 품질의 레벨 99 베이스 + 같은 카드 + 작업석 |
| 참 카드 + 참 옵션 작업석 | 선택한 접두사·접미사의 레벨 99 매직 참 + 같은 카드 + 작업석 |

카드와 재료는 돌려주므로 원하는 만큼 반복할 수 있다. 한 분류의 마지막 카드에서 ‘다음’을 누르면 첫 카드로, 첫 카드에서 ‘이전’을 누르면 마지막 카드로 순환한다.

중요: 호라드림 함이 생성한 장비는 D2R 엔진이 식별 플래그를 강제로 붙인다. 따라서 **정확한 이름 선택은 식별된 아이템**, **미확인 옵션 굴림은 도박**을 사용해야 한다. 이 제한을 우회하려면 실행 코드 훅이 필요한데, 현재 정만서버는 안전성과 버전 호환성을 위해 그런 훅을 사용하지 않는다.

## 선택 카드 시작 위치

| 상인 | 분류와 첫 카드 |
| --- | --- |
| 아카라 | 유니크 18분류, 세트 9분류, 베이스 15분류, 룬·보석·참/주얼 3분류, 스킬참 8분류, 인기 스몰참·라지참 2분류의 첫 카드 — 총 55장 |

상점에 여러 시작 카드가 한 번에 표시되므로 카드 이름과 위 표를 보고 분류를 고른다.

## 설치와 무결성

런처 설정의 **D2RLoader 설치**를 누르면 보급소·전체 지도 데이터 247개 파일도 `mods\JMServer\JMServer.mpq` 아래에 설치된다. 정확 아이템 550개, 베이스 508개, 재료 71개, 참 46개로 총 1,175개의 선택 카드와 제어 작업석 19개가 있으며, 전용 아이콘은 76종(일반·저사양 스프라이트 152개)이다. 추가 큐브식은 선택·생성·작업대·빠른 크래프트를 합쳐 5,839개다. 이후 실행할 때마다 런처가 파일별 SHA-256과 D2R/D2RLoader 버전을 검사하며, 파일이 바뀌거나 빠지면 게임을 실행하지 않는다.

카탈로그와 전체 지도는 `pinkufairy/D2R-Excel`의 고정 리비전 `cb27a8f574b873807e15cf9613d04d655cabdb60`에서 생성한다. 생성기는 입력 18개 파일의 해시가 모두 일치할 때만 빌드하며, 결과에는 게임 버전·소스 리비전·파일별 해시가 기록된다.

## 안전 범위

- 정만서버 전용 모드와 전용 세이브 경로에서만 사용한다.
- Battle.net Online에서는 사용하지 않는다.
- D2RLoader의 콘솔, 디버그 기능, 전역 확장, 모드 확장은 계속 비활성화한다.
- 게임 업데이트 후에는 새 버전을 검증하기 전까지 실행을 거부한다.
- 기본 싱글 캐릭터와 Battle.net 캐릭터 데이터에는 접근하지 않는다.

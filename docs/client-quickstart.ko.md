# 정만서버 Windows 사용법

이 런처는 D2R `3.2.92777`, D2RLoader `1.0.1-beta`, 정만서버 프로토콜 v7에 고정되어 있습니다. 서버가 플레이를 대신 실행하는 구조가 아니므로 각 플레이 PC에는 정식 D2R 설치와 해당 계정의 게임 이용 권한이 필요합니다.

## 최초 설정

1. `정만서버.exe`를 실행하고 **설정** 탭을 엽니다.
2. 서버 주소·포트, 인증서 SHA-256, 서버에서 발급받은 장치 ID와 토큰을 입력합니다.
3. **연결 시험**으로 서버 인증과 캐릭터 조회를 확인합니다.
4. D2R 설치 폴더와 `D2RLoader-1.0.1-beta.zip` 원본 파일을 선택합니다.
5. **화면 모드**에서 `전체 화면 (모니터 해상도)` 또는 `창 모드`를 선택합니다. 창 모드에서는 아래 해상도 목록에서 원하는 크기를 선택합니다.
6. Battle.net, Agent, D2R, D2RLoader를 모두 종료한 뒤 **D2RLoader 설치**를 누릅니다. 이때 인게임 아이템 보급소 데이터도 함께 설치됩니다.
7. **설정 저장**을 누릅니다.

연결 정보는 내부 호환 경로 `%LOCALAPPDATA%\JM Server\client-profile.json`에 저장됩니다. 장치 토큰은 현재 Windows 사용자 범위의 DPAPI로 암호화되므로 다른 Windows 계정이나 PC에 프로필 파일만 복사해도 사용할 수 없습니다. 게임 경로는 같은 폴더의 `launcher-preferences.json`에 저장됩니다.

D2RLoader ZIP은 배포 파일에 포함되지 않습니다. 프로젝트가 검증한 `1.0.1-beta` 원본을 각 플레이 PC에서 별도로 준비해야 합니다.

화면 해상도 프리셋은 `1280×720`, `1366×768`, `1600×900`, `1920×1080`, `1920×1200`, `2560×1080`, `2560×1440`, `2560×1600`, `3440×1440`, `3840×2160`입니다. 창 모드는 선택한 크기를 정만서버 전용 `Settings.json`에 적용합니다. D2R의 전체 화면은 별도 해상도를 선택하는 방식이 아니라 Windows 바탕화면 해상도를 사용하며, 해상도 선택값은 나중에 창 모드로 바꿀 때 사용할 값으로 보존됩니다. 이 설정은 혼자 플레이·PK 방 생성·PK 방 참가에 모두 동일하게 적용되고 다른 그래픽 옵션은 변경하지 않습니다.

정만서버 전용 `Settings.json`은 계정과 장치 ID 조합별로 서버에 백업됩니다. 플레이 시작 전에 해당 PC 설정을 내려받고 게임 종료 후 다시 저장하므로 밝기·소리·조작·화면 설정이 다음 실행에도 유지됩니다. 서버에 저장본이 없는 첫 실행은 현재 PC 설정을 그대로 사용하며 첫 정상 종료 때 서버에 등록합니다. 다른 PC는 장치 ID가 다르므로 자기 설정을 별도로 가집니다. 장치 토큰, 서버 주소, D2R 경로와 D2RLoader ZIP 경로는 서버로 전송하지 않습니다.

## 플레이

1. Battle.net, Agent, D2R, D2RLoader가 모두 종료됐는지 확인합니다.
2. **플레이** 탭에서 **새로고침**을 누릅니다.
3. 서버 전용 캐릭터를 선택하고 **선택 캐릭터 혼자 플레이**를 누릅니다.
4. 열린 게임에서는 TCP/IP만 사용하고 Online 탭은 열지 않습니다.
5. 게임을 정상 종료하면 런처가 프로필을 서버에 자동 체크인할 때까지 기다립니다.

종료 로그에는 `프로필 리비전 … 저장 완료`와 `개인 설정을 서버에 저장했습니다`가 표시됩니다. 캐릭터·공유 창고를 먼저 안전하게 체크인한 다음 개인 설정을 별도 저장하므로, 개인 설정 저장만 실패하면 경고를 남기고 캐릭터 저장 결과는 유지됩니다.

런처는 계정의 캐릭터와 공유 창고를 한 프로필로 체크아웃합니다. 기존 `Mods\JMServer` 세이브가 있으면 삭제하지 않고 `%LOCALAPPDATA%\JM Server\quarantine`으로 옮깁니다. 게임 중 새로 만든 미등록 캐릭터도 체크인 전에 같은 위치로 격리하며 서버에는 올리지 않습니다.

같은 계정의 소프트코어 캐릭터는 하나의 공유 창고를 사용합니다. 첫 캐릭터 생성 시 일반 공유 탭 5개에 각각 250만 골드가 들어가며, 고급 공유 탭에는 게임 데이터상 중첩 가능한 전체 91종이 각각 D2R의 실제 최대치 99개로 지급됩니다. 보석·해골 35종, 룬 33종, 활력 물약, 공포의 열쇠·장기, 면죄 재료, 월드스톤 조각과 고대 소환 재료가 포함됩니다. 이후 새 캐릭터를 만들 때도 기존 창고 아이템을 보존하면서 91종을 다시 99개로 보충합니다. 하드코어 공유 창고와 골드는 별도로 관리됩니다.

런처의 **사용 가이드** 버튼을 누르면 설치 파일에 포함된 한국어 통합 웹 가이드를 기본 브라우저로 열 수 있습니다. 인터넷 연결 없이도 동작하며, 1,175개 선택 대상과 추가 큐브식 5,839개(작업대 91개·빠른 크래프트 36개 포함)의 정확한 수치·전체 조합 규칙·설치부터 PK와 복구까지의 순서를 검색할 수 있습니다.

정상 종료하면 프로필 전체가 서버에 체크인되고 `Mods\JMServer`의 관리 대상 캐릭터·공유 창고 파일은 제거됩니다. 기본 싱글 저장 폴더는 변경하지 않으므로 정만서버 캐릭터와 싱글 캐릭터는 공유되지 않습니다.

## 인게임 아이템 보급소

런처의 별도 에디터 없이 게임 안에서 아이템을 얻습니다.

- **미확인 아이템**: 도박 상점에서 원하는 기본 장비를 구매합니다. 유니크 1%, 세트 1%, 레어 80%, 매직 18%입니다. 유니크·세트·룬워드·큐브 제작식의 숫자 가변 수치와 베이스 방어력은 원래 범위의 상위 25%, 매직·레어 접사와 직업 전용 자동 옵션은 상위 10%에서만 결정됩니다. 매직과 레어가 같은 접사 표를 사용하므로 고레벨 접사 가중과 수치 개선은 두 품질에 함께 적용됩니다. 직업·스킬 ID, 발동 확률·기술 레벨 복합값, 시각 효과, 역방향 요구 조건은 편향하지 않습니다. 기본형과 업그레이드형의 기준 비용은 1골드이며, 무기·방어구에는 D2R 엔진의 레벨 기반 최소 도박 비용이 추가됩니다.
- **도박 가격 할인**: 아카라의 일반 상점에서 초록색 `유니크 선택: 기드의 행운` 카드를 삽니다. 다른 이름이면 카드+마을 차원문의 두루마리는 다음, 카드+감별의 두루마리는 이전 항목으로 이동합니다. 카드+열쇠를 변환하고, 나온 기드의 행운을 인벤토리에 두면 상점과 도박 가격이 99% 감소합니다. 모드 적용 후 몬스터가 드롭한 새 기드의 행운에도 같은 할인이 붙습니다.
- **일반·고급·매직·에테리얼 베이스**: 아카라가 무기 8분류와 방어구 7분류의 첫 베이스 선택 카드, 일반·고급·매직 크래프트·에테리얼·고급 에테리얼 작업석을 팝니다. 카드+작업석으로 아이템 레벨 99 베이스를 만들며 카드와 작업석은 반환됩니다. 내구도가 없거나 원래 에테리얼이 될 수 없는 장비에는 에테리얼 조합이 없습니다.
- **정확한 아이템**: 액트 1 아카라가 파는 55개 분류의 첫 선택 카드를 호라드림 함에서 두루마리로 넘깁니다. 유니크·세트·재료 카드는 열쇠와, 베이스·스킬참·스몰참·라지참 카드는 전용 작업석과 조합합니다. 선택기의 아이템 이름은 한국어 클라이언트의 공식 번역으로 표시됩니다.
- **참 선택기**: 8직업×3계열 스킬참 24종과 자주 쓰는 접두사를 고정한 스몰참 11종·라지참 11종을 제공합니다. 생명력·타격 회복·달리기·힘·민첩 작업석과 스몰참 전용 마법 발견 작업석으로 원하는 접미사를 고정할 수 있습니다.
- **빠른 크래프트**: 베이스 카드+마법 크래프트 베이스 작업석으로 레벨 99 매직 재료를 만든 뒤 빠른 크래프트 작업석과 조합합니다. 원본 Blood·Caster·Hit Power·Safety 제작식 36종의 재료 묶음을 작업석 하나로 대체하고, 원본 고정 옵션과 최대 무작위 접사 4개 규칙을 유지합니다.
- **무지개 자락**: 유니크 부적·보석 카드에서 번개·냉기·화염·독과 사망 시·레벨 상승 시가 구분된 8종 중 하나를 고릅니다. 생성되는 피해 증가/저항 감소 수치는 `+5% / -5%`입니다.
- 함으로 정확히 생성한 아이템은 게임 엔진 특성상 식별된 상태입니다. 미확인 상태가 필요하면 도박을 사용합니다.
- 기드의 행운·애니힐러스·지옥불 횃불은 서로 다른 단일 소지 그룹입니다. 같은 종류는 1개만 들 수 있지만 세 종류는 각각 1개씩 동시에 소지할 수 있습니다. 선택 카드로 생성한 것도 같은 제한을 받습니다.
- 지옥불 횃불의 직업 기술은 아마존·원소술사·강령술사·성기사·야만용사·드루이드·암살자·워락 8직업 전체에서 결정됩니다.
- 베이스 선택 카드는 상점에서 잘리지 않도록 모두 1×1 최상급 다이아몬드 아이콘으로 표시됩니다. 열쇠로 생성한 실제 장비는 원래 아이콘·칸 크기를 그대로 사용합니다. 재료 선택 카드는 대상 재료와 같은 아이콘·칸 크기를 사용합니다.
- 참과 주얼 재료 분류에서는 중복되는 일반 거대 부적을 제외하고 작은 부적·큰 부적·주얼만 제공합니다. 기드참·파괴참 같은 유니크 거대 부적은 그대로 제공됩니다.

## 전체 지도 공개

마을·야외·던전을 포함한 유효 레벨 프리셋 1,092개의 전체 자동지도가 구역 진입 즉시 공개됩니다. `Tab`으로 원래 자동지도를 켜면 되며 별도 오버레이나 메모리 패치는 사용하지 않습니다. 난이도별 `.ma0`~`.ma3`와 `.map` 보조 파일도 캐릭터와 함께 서버에 저장됩니다.

상인별 분류와 조합법은 [인게임 아이템 보급소](unidentified-item-supply.ko.md)에 정리되어 있습니다.

## 서버 전용 캐릭터 생성

플레이 탭에서 **캐릭터 생성**을 누르고 이름과 직업을 선택합니다. 생성 프리셋은 하나로 통합되어 별도로 선택하지 않습니다.

- **완성 캐릭터**: 레벨 99, 모든 난이도·퀘스트·웨이포인트 완료, 미사용 스탯 505·스킬 110
- 황금 새 생명력 +60과 안야 모든 저항 +30을 포함해 세 난이도의 영구 퀘스트 보상이 적용됩니다. 장비와 참을 모두 벗은 헬 난이도 원소 저항은 기본 페널티 -100에 안야 보상 +30이 더해진 **-70**이 정상입니다.
- 인벤토리에 호라드릭 큐브가 기본 지급됩니다.

장비는 지급하지 않습니다. 생성된 캐릭터는 서버에만 저장되며 다음 플레이 때 체크아웃됩니다. 계정당 최대 8명이고, 플레이 또는 복구 프로필 임대 중에는 생성할 수 없습니다. 모든 직업은 고급 보관함을 사용할 수 있도록 Reign of the Warlock 저장 형식으로 생성되므로 플레이 PC에 해당 DLC가 설치되어 있어야 합니다. 직업은 사용자가 고른 직업 그대로 유지됩니다.

## 캐릭터 관리와 휴지통

캐릭터를 선택하고 **캐릭터 관리**를 누르면 현재 기본 능력치와 미사용 스탯을 확인할 수 있습니다.

- **이름 변경**: D2S 내부 이름과 서버 프로필 파일명을 한 번에 변경합니다.
- **스탯 초기화**: 지금까지 획득한 총 포인트는 그대로 유지하고 힘·민첩·활력·마력을 직업 기본값으로 되돌립니다. 환급된 포인트는 게임 안에서 다시 배분합니다.
- **휴지통으로 이동**: 캐릭터와 `.d2s`·보조 파일을 서버 휴지통에 보존하고 활성 프로필에서 제거합니다.
- **캐릭터 휴지통**: 삭제된 캐릭터와 보조 파일을 원래 상태로 복구합니다.
- **영구 삭제**: 휴지통의 캐릭터와 이전 버전을 완전히 제거합니다. 확인 후에는 복구할 수 없습니다.

관리 작업은 게임 또는 복구 프로필 임대 중에는 실행되지 않습니다. 서버는 변경 전 계정 프로필과 캐릭터 버전을 보존하고 감사 기록을 남깁니다. 스탯 초기화는 아이템과 스킬을 변경하지 않습니다.

## PK 방 만들기와 참가

호스트는 캐릭터를 선택하고 **PK 방 만들기**를 누릅니다. 친구에게 공개할 IPv4를 입력하면 정만서버 로비에 3분 만료 방이 생성되고 D2RLoader가 실행됩니다. 게임 안에서 **TCP/IP → 방 만들기**를 선택합니다.

참가자는 **방 목록 새로고침** 후 캐릭터와 참가 가능한 방을 선택하고 **선택 방 참가**를 누릅니다. 런처가 로컬 중계 주소 `127.0.0.1`을 클립보드에 복사하고 D2RLoader를 실행합니다. 게임 안에서 **TCP/IP → 참가**를 선택한 뒤 `Ctrl+V`로 주소를 붙여넣습니다.

- D2RLoader가 공식 자동 방 생성·참가 실행 인자를 제공하지 않으므로 게임 안의 마지막 선택은 직접 해야 합니다.
- 공개 게임 포트는 호스트 PC의 TCP `15571`입니다. 런처가 D2R의 로컬 TCP `4000`으로 자동 중계합니다.
- 같은 LAN/VPN에서도 방 생성 창에는 친구가 접근할 수 있는 호스트 IPv4를 입력합니다.
- 인터넷 직결이면 공유기에서 TCP `15571`을 호스트 플레이 PC의 TCP `15571`로 포트포워딩하고 공인 IPv4를 입력합니다.
- 호스트 플레이 PC의 관리자 PowerShell에서 `configure-jm-game-port.ps1 -AllowAnyRemoteAddress`를 한 번 실행합니다. 실제 사용에서는 `-AllowedRemoteAddress 친구공인IP`가 더 안전합니다.
- 정만서버 TCP `15570`은 인증·캐릭터·로비용이며 게임 트래픽을 중계하지 않습니다.
- 참가 화면에는 호스트 주소가 아니라 런처가 복사한 `127.0.0.1`을 입력합니다.
- 방은 플레이 중 자동 갱신되고 호스트가 종료하면 닫힙니다.

## 강제 종료 복구

게임, PC 또는 네트워크가 비정상 종료되면 런처 상단에 **복구 필요**가 표시됩니다. 새 플레이를 시작하지 말고 D2R과 D2RLoader를 종료한 뒤 **복구 체크인**을 누릅니다.

서버 임대가 다른 장치로 넘어갔거나 로컬 파일이 손상된 경우 자동 복구가 거부될 수 있습니다. 이때는 `%LOCALAPPDATA%\JM Server`와 `Saved Games\Diablo II Resurrected\Mods\JMServer`를 삭제하지 말고 관리자 복구를 진행해야 합니다.

## 주의 사항

- 정만서버는 Battle.net에 접속하거나 Battle.net 데이터를 수정하지 않습니다.
- D2RLoader 사용 중에는 Battle.net Online 탭에 접속하지 않습니다.
- 아이템 보급소는 `JMServer` 모드에서만 사용하고 일반 싱글 또는 다른 모드로 파일을 옮기지 않습니다.
- 인증서 SHA-256이 바뀌면 자동 우회하지 않고 연결을 거부합니다.
- 장치 토큰이 노출되면 서버에서 해당 장치 토큰을 즉시 재발급해야 합니다.
